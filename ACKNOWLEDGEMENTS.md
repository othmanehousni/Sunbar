# Acknowledgements

Sunbar was developed using the following implementation references.

- [Vorssaint](https://github.com/vorssaint/vorssaint-utils), particularly its Extra Brightness implementation, informed the EDR trigger and window placement. Licensed under GPLv3.
- [CoreAnimationPrivate](https://github.com/kageroumado/core-animation-private) documents the Core Animation backdrop interface used by Native HDR.
- [Harmaline](https://github.com/kageroumado/harmaline) informed the experimental framebuffer recovery mechanism. Its MIT notice is reproduced below.

Sunbar uses Apple's SwiftUI, AppKit, QuartzCore, Metal, CoreGraphics, IOKit, ColorSync, and ServiceManagement frameworks.
