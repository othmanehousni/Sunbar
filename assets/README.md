# Sunbar icon

`sunbar.png` is the source artwork for the app icon and repository logo. `build.sh` generates the standard macOS icon sizes and embeds `AppIcon.icns` in the app bundle.

The artwork was generated with the built-in image generation tool for this project and is covered by the repository license.

## Generation prompt

> Create one polished macOS application icon for Sunbar, an open-source menu-bar utility that boosts XDR display brightness. Use a clean geometric rising sun above a single horizontal bar, with five short, bold, evenly spaced rays around the upper semicircle. The sun and bar form one distinctive compact silhouette, in warm amber, centered on a deep ink-navy macOS rounded-square tile. The tile has a restrained soft edge and very subtle depth, like a carefully made native Mac utility icon. Keep the geometry simple and readable at 16 pixels. Single centered icon on a 1024 by 1024 transparent canvas, with an approximately 840 by 840 rounded-square tile and even transparent padding around it. Crisp edges, deliberate optical alignment, balanced proportions. Deliver only the finished icon artwork, without typography, lettering, watermarks, mockups, device frames, extra symbols, or surrounding scenery.
